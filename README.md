In this demo, we will work with the 1D Carleman linearized Burgers' equation and do the following:
- A linear combination of non-unitaries (LCNU) procedure is used to efficiently decompose the Carleman matrix.
- Show that the LCNU decomposition is more efficient than the Pauli decomposition.
- The variational quantum linear solver (VQLS) is used to obtain a solution for a small sample problem.
- Prove that the LCNU approach can efficiently load the 1D Carleman Burgers' equation as $n_x$ and $n_t$ are scaled up exponentially.

- The main program is run with Solve_Burgers.ipynb.
